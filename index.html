Resumen de Fórmulas de Integración Numérica

1. Regla del Trapecio Compuesta

Aproxima la función mediante segmentos lineales. Válida para cualquier número de subintervalos $n \ge 1$.

I_T = (h / 2) * [ f(x_0) + 2 * sum_{i=1}^{n-1} f(x_i) + f(x_n) ]
2. Regla de Simpson 1/3 Compuesta

Aproxima mediante parábolas de 2do grado. Requiere que el número de subintervalos $n$ sea **PAR**.

I_{S1/3} = (h / 3) * [ f(x_0) + 4 * sum_{impar} f(x_i) + 2 * sum_{par} f(x_i) + f(x_n) ]
3. Regla de Simpson 3/8 Compuesta

Aproxima mediante cúbicas de 3er grado. Requiere que $n$ sea **MÚLTIPLO DE 3**.

I_{S3/8} = (3h / 8) * [ f(x_0) + 3*f(x_1) + 3*f(x_2) + 2*f(x_3) + ... + f(x_n) ]
4. Método Combinado Híbrido (Simpson 1/3 + 3/8)

Permite integrar con precisión polinomial cuando $n$ es impar (e.g., $n=7$ u $n=11$). Se aplican $n-3$ subintervalos con Simpson 1/3 y los últimos 3 con Simpson 3/8.

I_{Comb} = I_{S1/3}(x_0 \dots x_{n-3}) + I_{S3/8}(x_{n-3} \dots x_n)
